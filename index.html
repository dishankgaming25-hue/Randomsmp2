GOT QUESTIONS?

QUICK ANSWERS.

How do I join the server?+

Open Minecraft, add a multiplayer server, and enter Randomsmp.softhost.pro. Bedrock players should also enter port 19186.

Can Java and Bedrock players join?+

Java players use the server address shown above. Bedrock players use the same address with port 19186.

Are ranks required to play?+

No. Iron is the default free rank. All paid ranks are optional.

Where can I get help or meet the community?+

Join our Discord community to ask questions and connect with other players.
